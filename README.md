# نظام التميز المؤسسي - هيئة الشارقة للإذاعة والتلفزيون

## نظرة عامة

نظام التميز المؤسسي هو تطبيق ويب تفاعلي مطور باستخدام React يهدف إلى إدارة مبادرات التميز المؤسسي ونقاط الجائزة. يتميز النظام بقدرته على العمل بشكل كامل أوفلاين مع إمكانيات شاملة لإدخال وتحليل وتصدير البيانات.

## التقنيات المستخدمة

النظام مبني على مجموعة من التقنيات الحديثة التي تضمن الأداء العالي والموثوقية. يستخدم **React 19** كإطار عمل أساسي مع **Vite** كأداة بناء سريعة ومحسنة. لإدارة البيانات المحلية، يعتمد النظام على **Dexie.js** التي توفر واجهة سهلة للتعامل مع IndexedDB. التصميم منفذ باستخدام **Tailwind CSS** مع مكونات **shadcn/ui** لضمان واجهة مستخدم حديثة ومتجاوبة.

للرسوم البيانية التفاعلية، يستخدم النظام مكتبة **Recharts** التي توفر مخططات قابلة للتخصيص وسريعة الاستجابة. وظائف الاستيراد والتصدير مدعومة بمكتبات **SheetJS** لملفات Excel و **jsPDF** لإنشاء تقارير PDF. النظام مصمم كتطبيق ويب تقدمي (PWA) مع **Service Workers** لضمان العمل أوفلاين.

## الهيكل التقني

### قاعدة البيانات المحلية

النظام يستخدم IndexedDB لتخزين البيانات محلياً في متصفح المستخدم. الهيكل يتضمن ثلاث جداول رئيسية: جدول الإدارات (departments) الذي يحتوي على معرف فريد واسم الإدارة، جدول المبادرات (initiatives) الذي يشمل جميع تفاصيل المبادرات من الاسم والإدارة والحالة والميزانية، وجدول نقاط الجائزة (award_points) الذي يحفظ نقاط القوة والتحسين مع ربطها بالمعايير والإدارات.

### مكونات الواجهة

الواجهة مقسمة إلى مكونات منطقية منفصلة. المكون الرئيسي (App.jsx) يدير الحالة العامة والتنقل بين التبويبات. كل تبويب له مكون منفصل: OverviewTab للنظرة العامة، PerformanceTab لتحليل الأداء، FinancialTab للتحليل المالي، DetailsTab لعرض التفاصيل، وAwardTab لإدارة نقاط الجائزة.

نوافذ الحوار منفصلة في مكونات مستقلة: AddInitiativeDialog لإضافة المبادرات، AddAwardPointDialog لإضافة نقاط الجائزة، وImportExportDialog لعمليات الاستيراد والتصدير. المكونات الإضافية تشمل OfflineStatus لعرض حالة الاتصال وPWAInstallPrompt لتشجيع تثبيت التطبيق.

## الميزات الوظيفية

### إدارة البيانات

النظام يوفر واجهات شاملة لإدارة المبادرات ونقاط الجائزة. يمكن للمستخدمين إضافة مبادرات جديدة مع تحديد جميع التفاصيل المطلوبة من الاسم والإدارة المسؤولة والحالة ونسبة الإكمال والميزانيات. كل مبادرة مرتبطة بإدارة محددة ومسؤول معين مع إمكانية تتبع التقدم المحرز.

نقاط الجائزة تصنف إلى نقاط قوة ونقاط تحسين، مع ربطها بالمعايير المختلفة وتصنيفاتها الفرعية. النظام يدعم عشرة معايير رئيسية تشمل الممكنات والقيادة والاستراتيجية والموارد البشرية والشراكات والعمليات والنتائج المختلفة. كل معيار له تصنيفات فرعية محددة مسبقاً لضمان التوحيد القياسي.

### التحليل والتقارير

النظام يقدم تحليلات شاملة للبيانات من خلال رسوم بيانية تفاعلية ومؤشرات أداء رئيسية. لوحة المعلومات الرئيسية تعرض إحصائيات سريعة عن عدد المبادرات وحالاتها ونقاط الجائزة والميزانيات. الرسوم البيانية تشمل مخططات دائرية لتوزيع الحالات، مخططات أعمدة للمقارنة بين الإدارات، ومخططات خطية لتتبع التقدم عبر الزمن.

تحليل الأداء يركز على نسب الإكمال والتقدم المحرز حسب الإدارات مع تقييمات الأداء. التحليل المالي يقارن الميزانيات المخططة مع المستخدمة ويحسب مؤشرات الكفاءة المالية. تقارير الجائزة تحلل توزيع نقاط القوة والتحسين حسب المعايير والإدارات.

### الاستيراد والتصدير

النظام يدعم تصدير البيانات بتنسيقات متعددة لضمان المرونة في الاستخدام. ملفات Excel تحتفظ بالتنسيق والألوان مع عرض البيانات في جداول منظمة. ملفات CSV توفر تنسيق نصي بسيط للتكامل مع أنظمة أخرى. تقارير PDF تقدم ملخصات شاملة مع رسوم بيانية ومؤشرات أداء مناسبة للعرض والطباعة.

الاستيراد يدعم ملفات Excel وCSV مع التحقق التلقائي من صحة البيانات. النظام يتعرف على تنسيق الملف تلقائياً ويحدد نوع البيانات (مبادرات أو نقاط جائزة) بناءً على الأعمدة الموجودة. عملية الاستيراد تتضمن تقرير مفصل عن النجاح والأخطاء مع إرشادات لإصلاح المشاكل.

## العمل أوفلاين

### تقنية PWA

النظام مطور كتطبيق ويب تقدمي يمكن تثبيته على الأجهزة المختلفة. Service Worker يدير التخزين المؤقت للملفات الأساسية ويضمن عمل التطبيق حتى بدون اتصال إنترنت. الملفات المخزنة تشمل JavaScript وCSS والخطوط والأيقونات الأساسية.

استراتيجية التخزين المؤقت تعتمد على "Cache First" للملفات الثابتة و"Network First" للبيانات الديناميكية. عند انقطاع الاتصال، يعرض النظام إشعار للمستخدم ويستمر في العمل بالبيانات المحلية. عند استعادة الاتصال، يتم تحديث الملفات المؤقتة تلقائياً.

### إدارة البيانات المحلية

جميع البيانات محفوظة في IndexedDB الخاص بالمتصفح مع نظام نسخ احتياطي متقدم. البيانات مشفرة بالتشفير الافتراضي للمتصفح ولا تغادر الجهاز المحلي. النظام يدعم تصدير نسخ احتياطية كاملة بتنسيق JSON لضمان عدم فقدان البيانات.

التزامن مع الخوادم الخارجية غير مطلوب حالياً، لكن البنية التحتية جاهزة لإضافة هذه الميزة مستقبلاً. النظام يتتبع تواريخ الإنشاء والتحديث لكل عنصر بيانات لتسهيل المزامنة المستقبلية.

## التثبيت والنشر

### متطلبات التطوير

لتطوير النظام محلياً، يتطلب الأمر Node.js إصدار 18 أو أحدث مع مدير الحزم pnpm. بعد استنساخ المشروع، يتم تثبيت التبعيات باستخدام `pnpm install` ثم تشغيل خادم التطوير بـ `pnpm dev`. النظام سيكون متاحاً على المنفذ 5173 افتراضياً.

### البناء والنشر

لبناء النظام للإنتاج، يستخدم الأمر `pnpm build` الذي ينشئ مجلد `dist` يحتوي على الملفات المحسنة. هذه الملفات يمكن نشرها على أي خادم ويب ثابت مثل Apache أو Nginx أو خدمات الاستضافة السحابية.

النظام لا يتطلب خادم خلفي أو قاعدة بيانات خارجية، مما يجعل النشر بسيط ومباشر. ملفات PWA (manifest.json وsw.js) يجب نسخها إلى مجلد النشر لضمان عمل الميزات أوفلاين.

## الأمان والأداء

### أمان البيانات

البيانات محفوظة محلياً في متصفح المستخدم ولا تنتقل عبر الشبكة، مما يضمن أقصى درجات الخصوصية والأمان. IndexedDB محمية بسياسات الأمان الخاصة بالمتصفح وتتطلب نفس النطاق للوصول إليها. النظام لا يجمع أي بيانات تحليلية أو شخصية.

### تحسين الأداء

النظام محسن للأداء من خلال تقسيم الكود وتحميل المكونات عند الحاجة. الرسوم البيانية تستخدم تقنيات التحديث الذكي لتجنب إعادة الرسم غير الضرورية. البيانات مفهرسة في قاعدة البيانات المحلية لضمان سرعة البحث والاستعلام.

الذاكرة مدارة بعناية مع تنظيف المراجع غير المستخدمة تلقائياً. حجم الحزمة محسن من خلال استخدام Tree Shaking وضغط الملفات. النظام يدعم التحميل التدريجي للبيانات الكبيرة لتجنب تجميد الواجهة.

## الصيانة والتطوير المستقبلي

### إضافة ميزات جديدة

البنية التحتية للنظام مرنة وقابلة للتوسع. إضافة تبويبات جديدة يتطلب إنشاء مكون React جديد وتسجيله في التطبيق الرئيسي. إضافة أنواع بيانات جديدة يتطلب تحديث مخطط قاعدة البيانات وإنشاء نماذج الإدخال المناسبة.

النظام يدعم إضافة تقارير مخصصة من خلال إنشاء مكونات رسوم بيانية جديدة. التكامل مع أنظمة خارجية ممكن من خلال إضافة طبقة API مع الحفاظ على القدرة على العمل أوفلاين.

### التحديثات والصيانة

النظام مصمم للتحديث التلقائي من خلال Service Worker. عند نشر إصدار جديد، يتم تحديث الملفات المؤقتة تلقائياً مع الحفاظ على البيانات المحلية. المستخدمون يتلقون إشعار بتوفر تحديث جديد مع خيار إعادة التحميل.

قاعدة البيانات المحلية تدعم الترقية التلقائية للمخطط عند الحاجة. النظام يحتفظ بسجل إصدارات البيانات لضمان التوافق مع الإصدارات السابقة. النسخ الاحتياطية التلقائية تضمن عدم فقدان البيانات أثناء التحديثات.
